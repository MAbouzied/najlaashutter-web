# Design direction (client correction — post Phase 2A)

## Main website (Phase 2B+)

**Not a visual redesign.** Rebuild must look like the current WordPress site to the client.

- WordPress backup + live site = visual source of truth
- Same header, nav, colors, typography feel, sections, cards, buttons, footer, mobile patterns
- Replace implementation (no Bootstrap/jQuery/Swiper) while **matching appearance**
- Allowed changes: audit fixes only (broken links, htmcssjs assets, fake testimonials, performance, etc.)

## Exception: `/window-shutters-jeddah/`

- New conversion-focused **information architecture** (Hero → Trust → … → CTA)
- Must still use Najlaa logo, colors, typography, buttons, photography, brand feel
- Must not look like a different company

Phase 2A LP was built before this correction was formalized; review notes compare it to the live WP homepage patterns.
